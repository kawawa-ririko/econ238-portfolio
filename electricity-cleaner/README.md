# Is U.S. Electricity Actually Getting Cleaner?

Econ 238 SHOW ME — MY OWN topic.

## Main finding

Using the same EPA eGRID framework for 2010 and 2023:

- U.S. coal generation share: **44.8% → 16.1%**
- Natural gas: **24.0% → 43.2%**
- Wind + solar: **2.3% → 13.9%**
- National direct CO2 total output rate: **1,232.35 → 767.2 lb/MWh**
- Decline in direct CO2 per MWh: **37.7%**
